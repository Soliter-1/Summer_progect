# Программный комплекс «VectorField»

Комплект программной документации в соответствии с ГОСТ ЕСПД и исходный код модуля анализа векторных полей.

---

## Структура репозитория

```text
.
├── src/                                   # Исходный код C++ (Visual Studio)
│   ├── VectorField.cpp
│   ├── VectorField.h
│   └── VectorField.sln
│
├── Ведомость эксплуатационных документов/  # Документация в LaTeX (ГОСТ ЕСПД)
├── Описание применения/
├── Описание программы/
├── Пояснительная записка/
├── Программа и методика испытаний/
├── Руководство оператора/
├── Руководство программиста/
├── Руководство системного программиста/
├── Спецификация/
├── Текст Программы/
├── Техническое задание/
└── Формуляр/

 Технологический стек
Язык программирования: C++ (C++17 / C++20)

Среда разработки (IDE): Microsoft Visual Studio 2022

Верстка документации: LaTeX (pdfLaTeX / XeLaTeX)

 Сборка и запуск проекта
Требования к окружению
Для сборки и запуска исходного кода потребуется:

Windows 10 / 11

Visual Studio 2022 (с установленной рабочей нагрузкой «Разработка рабочих столов на C++»)

Инструкция по сборке C++ проекта
Перейдите в папку src/:

Bash
cd src
Откройте файл решения VectorField.sln в Visual Studio.

Выберите конфигурацию сборки (Release | x64).

Нажмите Ctrl + Shift + B или выберите в меню Сборка -> Собрать решение.

Компиляция документации (LaTeX)
Для сборки .pdf документов перейдите в нужную папку с документацией и скомпилируйте главный файл:

Bash
pdflatex main.tex
 Скачивание готовых сборок
Скомпилированный исполняемый файл (.exe) и финальные версии PDF-документов доступны для скачивания в разделе Releases данного репозитория.
